# Youssef Bounouacha — Portfolio

Personal portfolio site. Featured project: ConstruFlow Pro.

## Setup

```bash
pnpm install
pnpm dev
```

```bash
pnpm build
pnpm start
```

## Scripts

```bash
pnpm check:lint
pnpm check:format
pnpm check:types
pnpm check:build
pnpm check
pnpm format
```

- `src/content/site.ts` — profile, contact, experience, SEO
- `src/content/copy.ts` — EN / FR copy
- `public/Youssef-Bounouacha-Frontend-Engineer-CV.pdf` — CV download
